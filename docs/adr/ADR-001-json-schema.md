# ADR-001 — 출력은 자유 텍스트가 아니라 JSON 스키마

## 맥락
트랙 C(대조군)의 v0는 `[category] 답변문장` 형태 자유 텍스트를 반환한다 → 골든셋으로 채점 불가.
원칙 2("통과보다 증명")는 결정적 지표를 요구한다.

## 결정
`TriageResult`를 고정 JSON 스키마로 한다. `schema_version` 필드를 둔다.
`IRREVERSIBLE.md`에 등재 — 변경 시 스키마 버전 증가 + 마이그레이션.

## 결과
- 골든셋 정확도 측정 가능 (Gate A)
- 다운스트림 파싱 안정
- (비용) optional 필드 추가는 하위호환이라 마이그레이션 불필요

## 대안과 기각
- 자유 텍스트 + 파서: 파서가 또 다른 실패 지점
