# ADR-004 — 리뷰어 역할을 출력 스키마로 강제한다

## 맥락
ST-009: 리뷰어가 답변을 통째로 다시 쓰면 역할 이탈(F9). 집계자는 규칙 기반이어야 한다.

## 결정
- 리뷰어 출력 = `{agree: bool, objection: str|null}` 로 스키마 제한 — 자유 텍스트 draft 불가
- 리뷰어 프롬프트에 작성자와 **다른 관점** 주입("bug로 의심될 근거를 우선 찾아라")
- 집계자 = 규칙: 동의 → 작성자안 / 불일치 → 재작성 1회 / 여전히 불일치 → other/P3 강등
- `ConflictResolutionConfig(max_resolution_rounds=1)` — 재작성 루프 상한

## 결과
- Gate F `role_adherence` 측정 가능 — 리뷰어가 스키마 밖 출력을 내면 0
- 재작성 루프가 무한이 되지 않음

## 대안과 기각
- 집계자도 LLM: 판정에 판정을 얹어 비결정성 증폭. 규칙이 재현 가능
