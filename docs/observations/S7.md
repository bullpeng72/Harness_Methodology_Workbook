# 저자 관찰 — S7 (RCA 폐루프 검증 + 배포 + 성숙도)

## RCA 폐루프 완성 — `verify_recommendation_outcome` (실측)

S5에서 `diagnose`가 "C·D 공유원인 = SLA breach"를 지목 → S6에서 조치(Drafter 결정적화, ADR-005) →
S7에서 그 조치가 실제로 효과 있었는지 재평가로 확인:

```
verify_recommendation_outcome(v2, v3, target_gate="C") → confirmed  (0.597 -> 0.757, +0.160)
verify_recommendation_outcome(v2, v3, target_gate="D") → confirmed  (0.011 -> 0.570, +0.559)
```

`.aoo/recommendation_outcomes.jsonl` 에 2건 기록. `summarize_recommendation_outcomes` →
`{total:2, confirmed:2, refuted:0}`.

**폐루프 닫힘**: 감지(`gate`/`trend`) → 진단(`diagnose`) → 조치(사람) → 검증(`verify`) → 이력(JSONL).
"고쳤다"가 아니라 "고친 게 C·D 둘 다에서 confirmed 됐다"를 데이터로.

## "실제로 돌리니" (계속)

- `summarize_recommendation_outcomes` 는 **로드된 리스트**를 받는다 —
  `load_recommendation_outcomes(path)` 를 먼저 호출해야. 경로 문자열을 넘기면
  문자 순회 → `'/'.get()` → AttributeError. `record_recommendation_outcome` 는 경로를 받는데
  `summarize` 는 리스트를 받아 **비대칭** — 워크북 Ch 40에 명시할 것.
