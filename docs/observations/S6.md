## 이게 보여주는 것 (Part XI)

**한 조치(Drafter 결정적화)가 RCA로 특정한 공유 원인을 쳐서 C·D 둘 다 겨냥했다.**
"Gate C 고치고 Gate D 고치고"가 아니라 "공유 원인 하나 고치니 둘 다 움직였다".
트랙 C는 애초에 C·D를 따로 볼 축이 없어 이 최적화 자체가 발생하지 않는다.
